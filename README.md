# 關稅政策消息監控系統（第五組）

> **專案主旨**：建立一套全球關稅政策消息監控系統，持續讀取全球官方來源與新聞媒體，每天分類新動態，標出影響哪些全球金融標的，回答「今日關稅政策變化，以及明天需要注意哪些標的」。

## 🧭 核心運作流程

```
政策事件 ──> 國家 ──> 產品 ──> 產業 ──> 標的 ──> 影響方向 ──> 重要程度
```

1. **抓**：全球官方來源（USTR、各國商務部/海關）＋ 全球主要新聞媒體（Reuters、Bloomberg 等）。
2. **理**：AI 分析提取國家、產品、產業、政策狀態，並透過 `Event ID` 進行事件去重與聚合。
3. **映射**：三層標的映射機制（Level 1 人工資料庫、Level 2 AI 關聯推理、Level 3 信心分級）。
4. **看 & 監控化**：視覺化圖表與一鍵重跑流程（`python main.py`）。
5. **結論**：每日自動產出「明日觀察清單」決策日報。
